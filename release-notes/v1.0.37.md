# H1T.CC Tweak Utility V1 (Build 1.0.37)

- **Lizenzprüfung im Hintergrund startet den Tweaker nicht mehr, während er offen ist:** Bisher wurde die tägliche Prüfung bei jedem Start neu auf „in 15 Minuten“ gestellt und lief dadurch fast immer, während der Tweaker offen war. Das war der Auslöser für „PowerShell konnte nicht ausgeführt werden … tweaker.ps1 ist nicht vorhanden“. Eine bestehende Prüfung bleibt jetzt unverändert, eine neue läuft erst rund 23 Stunden später.
- Zusammen mit 1.0.36 (eigene Kopie der Skripte, nur ein Fenster) ist der Fehler damit doppelt abgesichert.

Das Update wird beim nächsten Start installiert, oder sofort über Einstellungen → **Jetzt neu starten**.
