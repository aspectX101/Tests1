# H1T.CC Tweak Utility V1 (Build 1.0.24)

- **Configs schalten keine Windows-Dienste mehr ab:** Auch „Ultimate“ lässt SysMain, DiagTrack und alle anderen Dienste jetzt an, ebenso Prefetch und den Aktivitätsverlauf. Manche FiveM-Server prüfen beim Screenshare, ob diese Dienste laufen. Einzeln lassen sich die Tweaks weiterhin schalten, mit Warnhinweis in der Beschreibung.
- **Wer Ultimate schon angewendet hat:** Unter **Dienste** auf **Revert All** klicken, dazu unter **Leistung** „Prefetch deaktivieren“ und unter **Datenschutz** „Aktivitätsverlauf deaktivieren“ ausschalten, dann den PC neu starten. Alle Werte kommen exakt so zurück, wie sie vorher waren.
- **„Überwachung gestört“** zeigt jetzt den Grund von Windows an und landet im Support-Bericht.

Das Update wird beim nächsten Start installiert, oder sofort über Einstellungen → **Jetzt neu starten**.
