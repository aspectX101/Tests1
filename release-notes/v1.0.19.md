# H1T.CC Tweak Utility 1.0.19

- **Klarere Meldung, wenn PowerShell nicht startet:** Statt nur „PowerShell konnte nicht ausgeführt werden“ steht jetzt der Grund von Windows dahinter, z. B. der Exit-Code oder „blockiert“. Der Grund landet auch im Support-Bericht (Einstellungen → Support → Support-Bericht exportieren). So lässt sich schnell erkennen, ob ein Virenscanner, eine Richtlinie oder ein anderes Tool PowerShell blockiert.

In der App die Einstellungen öffnen und nach dem Download auf **Jetzt neu starten** klicken.
