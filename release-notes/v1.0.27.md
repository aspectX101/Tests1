# H1T.CC Tweak Utility V1 (Build 1.0.27)

- **Displays-Seite repariert:** Auf PCs, auf denen die Windows-Einstellungen für Multiplane-Overlay (OverlayTestMode) oder Hardware-GPU-Planung (HwSchMode) nie gesetzt wurden, brach die Seite mit „Could not load display information“ ab. Das Update wird beim nächsten Start installiert, oder sofort über Einstellungen → **Jetzt neu starten**.
