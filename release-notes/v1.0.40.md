# H1T.CC Tweak Utility V1 (Build 1.0.40)

- **Neu: Lautstärkeregler auf der Spotify-Karte im Dashboard.** Der Regler stellt nur die Lautstärke von Spotify im Windows-Lautstärkemixer ein, nicht die des ganzen PCs. Kein Spotify-Login nötig.
- Ein Klick auf den Lautsprecher schaltet Spotify stumm und wieder an. Der Regler geht auch per Mausrad (5-%-Schritte) und mit den Pfeiltasten.
- Der Regler erscheint, sobald Spotify einen Ton abgespielt hat. Vorher hat Windows für Spotify noch keinen Eintrag im Lautstärkemixer.

Das Update wird beim nächsten Start installiert, oder sofort über Einstellungen → **Jetzt neu starten**.
