# H1T.CC Tweak Utility V1 (Build 1.0.30)

- **Tweaks funktionieren wieder, wenn Windows bereits einen Wiederherstellungspunkt hat:** Hatte Windows Update oder ein anderes Programm in den letzten 24 Stunden einen Wiederherstellungspunkt angelegt, lehnte Windows einen neuen ab – und jeder Tweak brach mit „Ungültige Antwort vom Backend“ ab. Jetzt nutzt der Tweaker in diesem Fall den vorhandenen, aktuellen Wiederherstellungspunkt. Gibt es keinen, bricht er wie bisher sicher ab, ohne etwas zu ändern.
- **Genauere Fehlermeldungen:** Wenn ein Tweak an Windows scheitert, zeigt die Meldung jetzt zusätzlich den technischen Grund in Klammern an.

Das Update wird beim nächsten Start installiert, oder sofort über Einstellungen → **Jetzt neu starten**.
