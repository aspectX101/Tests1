# H1T.CC Tweak Utility V1 (Build 1.0.43)

- **Neu: Weitere Tools → Energie.** Die Seite hat jetzt echte Funktionen:
  - **Energieplan** wechseln (alle Pläne, die Windows anbietet), wirkt sofort.
  - **Bildschirm ausschalten** und **Energiesparmodus** einstellen, am Netzteil und bei Laptops auch im Akkubetrieb.
  - **Akku-Anzeige** bei Laptops.
  - Die passenden **Energie-Tweaks** direkt auf der Seite.
- Die Originalwerte werden beim ersten Ändern gesichert; **Zurücksetzen** stellt sie wieder her. Endet die Lizenz, wird das ebenfalls zurückgesetzt.
- Werte, die gerade ein aktiver Tweak steuert (z. B. „Hohe Leistung“ den Energieplan), sind gesperrt und nennen den Tweak. So bleibt dessen Sicherung intakt.
- **Helles Design weicher:** ein angenehmes Hellgrau statt grellem Weiß, und das H1T-Logo hebt sich mit mehr Kontrast und dunklem Schein deutlich besser ab.

Das Update wird beim nächsten Start installiert, oder sofort über Einstellungen → **Jetzt neu starten**.
