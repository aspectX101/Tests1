# H1T.CC Tweak Utility 1.0.18

- **Von Windows zurückgesetzte Tweaks:** Setzt Windows Tweaks zurück, meist bei einem Windows-Update, zeigt das Dashboard das jetzt an und bietet **Erneut anwenden** an. Mit **Ausblenden** verschwindet der Hinweis, bis wieder etwas zurückgesetzt wird.
- **Support-Bericht:** Unter Einstellungen → Support speichert **Support-Bericht exportieren** eine Datei mit Systeminfos, Lizenz- und Update-Stand, aktiven Sicherungen und den letzten Fehlerprotokollen. Benutzernamen in Pfaden werden dabei ersetzt. Die Datei einfach an den Support schicken.
- **Genauere Fehlerprotokolle:** Schlägt ein Tweak fehl, merkt sich die App jetzt den genauen Grund, z. B. den Windows-Fehlercode.
- **Sicherere Updates:** Ab dem nächsten Update behält der Tweaker die vorherige Version. Startet eine neue Version zweimal nicht sauber, kehrt er automatisch zur vorherigen zurück und bietet die fehlerhafte Version nicht erneut an.
- **Mehr Prüfungen vor jedem Update:** Alle Backend-Tests laufen jetzt bei jeder Veröffentlichung automatisch auf Windows mit.

In der App die Einstellungen öffnen und nach dem Download auf **Jetzt neu starten** klicken.
