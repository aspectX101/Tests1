# H1T.CC Tweak Utility V1 (Build 1.0.33)

- **Grund bei „PowerShell konnte nicht ausgeführt werden“ auf allen Seiten:** Auch unter Sicherungen und auf allen anderen Seiten steht jetzt der Grund von Windows in Klammern dahinter, nicht nur in einzelnen Meldungen.
- **Support-Bericht:** enthält jetzt zusätzlich die Ergebnisse der Systemprüfung, also Grafiktreiber-Abstürze, plötzliches Ausgehen, Hardware-Fehler (WHEA) der letzten 30 Tage und das Alter des Grafiktreibers.

Das Update wird beim nächsten Start installiert, oder sofort über Einstellungen → **Jetzt neu starten**.
