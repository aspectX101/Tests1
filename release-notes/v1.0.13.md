# H1T.CC Tweak Utility 1.0.13

- **👁 Neue Startanimation für das dunkle Design – ein Auge aus Code** (ersetzt die Glock):
  - Auf fast schwarzem Hintergrund läuft dezent der Code des Tweakers, ein gebogener Strich aus Code erscheint – das geschlossene Auge.
  - Das Auge öffnet sich: das Weiße besteht aus Code-Zeilen entlang der Lider, die Iris aus leuchtend blauen Code-Ringen.
  - Es schaut sich mit schnellen Blicksprüngen um, blinzelt, schwebt leicht und folgt dann deiner Maus.
  - Die Kamera fährt in die Iris, das Auge schließt sich zu einem Code-Band, das zur Linie zusammenschrumpft.
  - Sobald der Tweaker bereit ist, blinzelt das Auge direkt in den Tweaker: es linst auf, blinzelt und öffnet sich weit – dahinter erscheint das Dashboard.
  - Mit Sound (Summen, Datenklicken, Blinzeln, ein tiefer Schlag beim Schließen, ein „Braam“ beim Öffnen) – abschaltbar unter **Einstellungen → Startanimation → Sound**.
- Kürzer als vorher (etwa 6 Sekunden), konstant 60 fps; ein Klick überspringt die Animation und öffnet das Auge sofort.

In der App die Einstellungen öffnen und nach dem Download auf **Jetzt neu starten** klicken.
