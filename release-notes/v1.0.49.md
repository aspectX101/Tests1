# H1T.CC Tweak Utility V1 (Build 1.0.49)

- **GPU-Auslastung im Dashboard stimmt jetzt mit dem Task-Manager überein.** Bisher zeigte der Tweaker oft viel zu niedrige Werte (z. B. 6 % statt 86 %), weil nur die 3D-Engine und veraltete Windows-Werte gelesen wurden. Jetzt misst er wie der Task-Manager: die am stärksten ausgelastete Engine der Grafikkarte (3D, Compute, Video, Kopieren).
- „Alle wiederherstellen“ wird jetzt bei jedem Update auf echtem Windows geprüft: alle Tweaks anwenden, zurücksetzen, jeden Wert mit dem Original vergleichen.

Das Update wird beim nächsten Start installiert, oder sofort über Einstellungen → **Jetzt neu starten**.
