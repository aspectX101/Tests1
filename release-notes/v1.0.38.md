# H1T.CC Tweak Utility V1 (Build 1.0.38)

- **Neu: Tweak-Liste per Klick auf dem Dashboard.** Ein Klick auf „Angewendete Tweaks“ zeigt alle Tweaks, die gerade auf deinem PC aktiv sind, nach Bereichen sortiert und mit Suchfeld. Das geht genauso bei „Verfügbare Tweaks“, „Sicher verfügbar“ und „Dienste optimiert“.
- Ein Klick auf einen Tweak in der Liste öffnet ihn direkt mit seinem Schalter, zum Ein- oder Ausschalten.
- Die Kacheln sind auch per Tastatur bedienbar (Tab, Enter), Escape schließt die Liste.

Das Update wird beim nächsten Start installiert, oder sofort über Einstellungen → **Jetzt neu starten**.
