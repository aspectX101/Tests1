# H1T.CC Tweak Utility V1 (Build 1.0.32)

- **Configs prüfen jetzt deinen PC:** Bevor Essential, Performance, Ultimate, die Empfehlung oder die Start-Buttons der Kategorien Tweaks anwenden, liest der Tweaker das Windows-Ereignisprotokoll der letzten 30 Tage. Tweaks, die auf deinem PC Probleme machen könnten, werden weggelassen. Den Grund siehst du auf der Config-Karte unter „Für deinen PC weggelassen“:
  - **Grafiktreiber-Abstürze** (z. B. DXGI_ERROR_DEVICE_HUNG): GPU-Tweaks bleiben aus.
  - **Plötzliches Ausgehen ohne sauberes Herunterfahren**, häufig ein Netzteil an der Grenze oder Überhitzung: Tweaks, die dauerhaft mehr Strom ziehen, bleiben aus.
  - **Hardware-Fehler** (WHEA, oft instabile Übertaktung): Leistungs- und GPU-Tweaks bleiben aus.
  - **Laptop, X3D-CPU, CPU mit Leistungs- und Effizienzkernen, alter Grafiktreiber, Riot Vanguard/FACEIT:** die jeweils unpassenden Tweaks bleiben aus.
- **Einzelne Schalter:** Schaltest du so einen Tweak von Hand ein, fragt der Tweaker mit dem Grund nach, bevor er ihn anwendet.
- Die Prüfung liest nur und bleibt auf deinem PC.

Das Update wird beim nächsten Start installiert, oder sofort über Einstellungen → **Jetzt neu starten**.
